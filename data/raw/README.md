# Raw data

Download the [Fake and Real News dataset](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset)
(ISOT, University of Victoria) and put `Fake.csv` and `True.csv` here:

```bash
kaggle datasets download -d clmentbisaillon/fake-and-real-news-dataset -p data/raw --unzip
```

The files are not committed to the repository.
